# جامع بيانات elCinema (مرخّص)

سكربت Python واحد (`elcinema_scraper.py`) يسحب الأفلام والمسلسلات من elcinema.com مع تفاصيلها،
ويكتشف **تلقائيًا** كل عمل جديد يُضاف إلى الموقع ويجلب بياناته.

## التثبيت

```bash
python3 -m venv .venv && source .venv/bin/activate     # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

### على ويندوز

1. ضع الملفات الثلاثة (`elcinema_scraper.py` و`requirements.txt` و`README.md`) في مجلد واحد، مثل `C:\elcinema`.
2. افتح CMD أو PowerShell **داخل هذا المجلد** (`cd C:\elcinema`). الأوامر تُنفَّذ من مجلد السكربت، وإلا ظهر «No such file or directory».
3. استخدم `python` أو `py` بدل `python3`، و`python -m pip` بدل `pip`:
```bat
cd C:\elcinema
python -m pip install -r requirements.txt
python elcinema_scraper.py inspect 2097372 --user-agent "my-project (contact: you@example.com)"
```
- حروف `--user-agent` إنجليزية فقط (ترويسات HTTP لا تقبل العربية).
- لعرض العربية في الطرفية: `chcp 65001` قبل التشغيل، أو استخدم Windows Terminal. حتى لو ظهرت الحروف مقطّعة فالبيانات المحفوظة سليمة (UTF-8).

## التشغيل التلقائي بلا تدخّل (ويندوز)

ضع هذه الملفات كلها في **مجلد واحد**: `elcinema_scraper.py` و`requirements.txt` و`install_autorun.ps1` و`INSTALL_AUTORUN.bat` و`UNINSTALL_AUTORUN.bat`، ثم انقر نقرًا مزدوجًا على **`INSTALL_AUTORUN.bat`** مرة واحدة. يسجّل ثلاث مهام في «مجدول المهام» تعمل في الخلفية **بلا أي نافذة**:

| المهمة | متى | ماذا تفعل |
|---|---|---|
| `ElCinema-Fast` | كل ساعة | اكتشاف الجديد (صفحات الجديد + sitemap + تتبع المعرّفات) وجلب تفاصيله، وإكمال ما تعثّر سابقًا |
| `ElCinema-Full` | عند تسجيل الدخول + يوميًا 03:30 | مسح فهارس 2026 وما بعدها كاملة (يلتقط كل ما فاته)، وتنزيل أول مرة |
| `ElCinema-Schedules` | كل 4 ساعات | لقطة مواعيد السينمات ودليل القنوات |

- **الاستدراك:** إن كان الجهاز مطفأً أو نائمًا وقت مهمة، تُنفَّذ فور عودته (`StartWhenAvailable`)، ولا تتداخل تشغيلتان (قفل `run.lock`)، وتتوقف أي مهمة عالقة بعد 12 ساعة.
- **أين النتائج:** `elcinema_data\elcinema.sqlite` (القاعدة)، و`new_items.jsonl` (كل عمل جديد مكتشف مع وقت اكتشافه)، و`autorun.log` (السجل، يُدوَّر عند 5MB).
- **للتحقق:** افتح «مجدول المهام» (Task Scheduler) ← المكتبة، وابحث عن `ElCinema-`. أو افتح `autorun.log`. ولرؤية عدد ما جُمع: `python elcinema_scraper.py stats`.
- **الإيقاف:** `UNINSTALL_AUTORUN.bat` يحذف المهام فقط ولا يمس بياناتك.
- **حدّ يجب معرفته:** المهام تعمل ما دام حسابك مسجّل الدخول على ويندوز، وحتى لو الشاشة مقفلة أو أنت بعيد. إن كان الجهاز مطفأً بالكامل فلا يعمل شيء حتى يُشغَّل، ثم يستدرك ما فات. ولو أردت جمعًا لا يتوقف والجهاز مطفأ فشغّل السكربت نفسه على خادم صغير (VPS) بـ cron.

## التأكد من أن الجديد يصل فعلًا: `verify`

```bat
VERIFY.bat            :: تقرير فقط (يُحفظ في verify_report.txt)
VERIFY.bat --fix      :: ويجلب فورًا أي ناقص
```
(أو `python elcinema_scraper.py verify`). لا يطمئنك بكلام، بل يقارن الموقع الحيّ بقاعدتك الآن:
1. **صحة التشغيل التلقائي:** متى آخر نجاح لكل مهمة (السريعة ≤ 3 ساعات، اليومية ≤ 30 ساعة، المواعيد ≤ 9 ساعات).
2. **فهارس السنوات الحيّة:** يعيد قراءة فهرس كل سنة ≥ 2026 ويعدّ ما هو موجود على الموقع وغير موجود عندك.
3. **صفحات الجديد** (يعرض الآن/قريبًا/القنوات)، 4. **sitemap** إن وُجدت، 5. **تتبع المعرّفات** بعد أحدث عمل عندك.
6. **مصدر اكتشاف** أعمالك، لتعرف أي طبقة تعمل فعلًا.

النتيجة ثلاثة أرقام: *على الموقع ولم يُكتشف* (يجب أن يكون 0، أو أعمالًا أُضيفت خلال الساعة الأخيرة فقط)، و*بانتظار الجلب*، و*وُسم «غير موجود» رغم ظهوره* (يجب أن يكون 0؛ إن لم يكن، أرسل لي الأمثلة). رمز الخروج 0 = سليم، 2 = توجد مشاكل.

**ما لا يضمنه (بصراحة):** عمل لا يظهر في فهرس سنته ولا في صفحات الجديد ولا في sitemap، ولا يقع معرّفه بعد أحدث معرّف عندك. هذا نادر، لكنه يعني أن «100%» ضمان لا يملكه أحد من الخارج. لذلك شغّل `VERIFY.bat` بعد أول يوم، ثم أسبوعيًا؛ فإن بقي «لم يُكتشف» صفرًا عدة مرات فالتغطية موثوقة عمليًا.

## من الجلب إلى الموقع: `elcinema_publish.py`

يحوّل كل عمل جديد إلى مقال **مختلف** (لا نسخ) ثم ينشره:
`جلب ← تحويل بالذكاء الاصطناعي من الحقائق ← بوابة عدم‑النسخ ← نشر`

```bat
set ANTHROPIC_API_KEY=...            :: مفتاح API (للتحويل)
python elcinema_publish.py run --no-publish --limit 3      :: جرّب أولًا: يحوّل ويفحص دون نشر
python elcinema_publish.py run --target wordpress --status draft
python elcinema_publish.py status                           :: العدّاد والمحجوز وأسبابه
```
- **الأهداف:** `jsonl` (ملف `site_items.jsonl` يستورده موقعك)، `wordpress` (REST API بكلمة مرور تطبيق: `WP_URL` و`WP_USER` و`WP_APP_PASSWORD`)، `webhook` (`WEBHOOK_URL` و`WEBHOOK_TOKEN`).
- **بوابة عدم النسخ (لإثبات التزامك بشرط الترخيص):** يُرفض أي نص تتجاوز عباراته المشتركة مع الملخص الأصلي 8% أو فيه مقطع منسوخ أكثر من 6 كلمات أو يذكر اسم المصدر. يُعاد التوليد مرة، وإلا يُحجز العمل (`held`) مع السبب.
- **لا يستنسخ:** التعليقات والصور لا تُنشر إطلاقًا؛ الملخص الأصلي يُستعمل للفهم والمقارنة فقط.
- **آمن للتكرار:** كل عمل يُولَّد وينشر مرة، ويُحدَّث فقط إذا تغيرت بياناته (يعدّل المنشور نفسه، لا يكرّره).
- **التكلفة:** `--limit 20` في الدورة الواحدة يحدّ الإنفاق على الـAPI.
- **على GitHub:** أضف الأسرار (Secrets) المذكورة، ومتغيّرَي المستودع `SITE_TARGET` و`PUBLISH_STATUS`. القيمة الافتراضية `draft`؛ بدّلها إلى `publish` حين تطمئن للجودة.
- **تحذير:** النشر الآلي الكامل دون أي مراجعة هو بالضبط ما تصنّفه Google وAdSense «محتوى مولّد آليًا». ابدأ بـ`draft` وراجع عيّنة أسبوعيًا، وأضف قيمة حقيقية (أخبار، قوائم، تحليل).

## ملخصات الحلقات: `elcinema_recaps.py`

```bat
set ANTHROPIC_API_KEY=...
python elcinema_recaps.py --no-publish --limit 3     :: جرّب أولًا: يبحث ويكتب ويفحص دون نشر
python elcinema_recaps.py --target wordpress --status draft --limit 10
```
لكل حلقة في قاعدة elcinema (2026 فصاعدًا): **بحث ويب بـClaude** عن أحداثها ← يُعتمد فقط الحدث الذي أكّده **موقعان مستقلان** موجودان فعلًا في نتائج البحث (أو ما ورد في ملخص elcinema) ← كتابة مقال بنمط وطول يتبدّلان من حلقة لأخرى ← بوابة (عدم نسخ، عبارات جاهزة، افتتاحية مكررة) ← نشر.
- **ما لم تؤكده مصادر كافية لا يُكتب:** تُحجز الحلقة (`held`) بدل اختلاق أحداثها.
- **تحذير حرق** يُضاف تلقائيًا، ورابط للمسلسل، وبيانات منظّمة `TVEpisode`.
- **الإفصاح:** متغيّر المستودع `DISCLOSURE_LINE` (أو `--credit-line`) يضع سطرًا أسفل المقال، مثل «أُعدّ بمساعدة الذكاء الاصطناعي وراجعه فريق التحرير».
- اسم أداة البحث قابل للتغيير عبر `WEB_SEARCH_TOOL` إن حدّثت Anthropic إصدارها.

## نطاق السنوات: من 2026 فقط

الافتراضي الآن `--min-year 2026`: لا يُحفظ إلا عمل سنته 2026 فما بعد، والقديم يُتجاهل تمامًا. يعمل الفلتر على مستويين:
- **عند الاكتشاف:** يُفحص فهرس 2026 وما بعده فقط (2027، وغيرها إن وُجدت أعمال معلنة لها)، ولا تُفحص فهارس السنوات القديمة. خيار `--categories` يُتجاهل لأنه يضم كل السنوات.
- **عند الجلب:** أي عمل قديم يظهر في صفحات الجديد (مثل إعادات التلفزيون) يُجلب له طلب واحد فقط لمعرفة سنته، ثم يُوسَم `skipped` في الطابور ولا يُعاد فحصه، ولا يُحفظ له طاقم أو إضافات أو مواعيد.

الأعمال المعلنة لسنوات قادمة (مثل مسلسلات رمضان 2027) تدخل افتراضيًا. إن أردت «حتى اليوم» بدقة فأضف `--max-year 2026`.
للعودة إلى كل السنوات: `--min-year 0`. ولتغيير البداية مثلًا: `--min-year 2025`.
في `--sitemap` تُستبعد الأعمال التي تاريخ تعديلها (`lastmod`) قبل 2026 إن وُجد، ومع ذلك قد يمرّ عمل قديم عُدّل مؤخرًا فيُتخطّى عند الجلب.

## البدء السريع (بهذا الترتيب)

```bash
# 1) اختبر المحلّلات على عمل واحد وراجع الحقول المستخرجة
python3 elcinema_scraper.py inspect 2097372 --user-agent "my-project (contact: you@example.com)"

# 2) جرّب سحب سنة واحدة صغيرة قبل القاعدة كلها
python3 elcinema_scraper.py backfill --years 2026 --limit 50

# 3) راجع النتيجة
python3 elcinema_scraper.py stats
python3 elcinema_scraper.py export --format jsonl --out out.jsonl

# 4) السحب الكامل (قابل للإيقاف والاستئناف بنفس الأمر)
python3 elcinema_scraper.py backfill
```

> إن ظهرت في `inspect` حقول فارغة تحت «⚠ حقول فارغة» فهذا يعني أن العمل لا يملك تلك البيانات،
> أو أن بنية الصفحة تختلف عمّا اعتمدتُ عليه — راجع قسم «تعديل المحلّلات» أدناه.

## الاكتشاف التلقائي للأعمال الجديدة

```bash
python3 elcinema_scraper.py update                 # سريع: /now /soon /tvguide /ramadan ... (كل ساعة مثلًا)
python3 elcinema_scraper.py update --mode full     # + فهارس السنة الحالية والقادمة كاملة (مرة يوميًا)
python3 elcinema_scraper.py watch --interval 3600  # حلقة دائمة بدل الجدولة الخارجية
```

كل عمل لم يكن في قاعدتك يُجلب بكامل تفاصيله، ويُطبع، ويُضاف سطرًا إلى `elcinema_data/new_items.jsonl`.

**Linux/macOS (cron):**
```cron
7 * * * *  cd /path/to/dir && .venv/bin/python elcinema_scraper.py update >> update.log 2>&1
40 3 * * * cd /path/to/dir && .venv/bin/python elcinema_scraper.py update --mode full >> update.log 2>&1
```
**ويندوز:** Task Scheduler ← Create Task ← Action: `python elcinema_scraper.py update` (Start in: مجلد السكربت).

لإضافة صفحة «أحدث الإضافات» إن عرفتَ رابطها: `update --extra-source https://elcinema.com/...`

### كيف يعرف السكربت أن عملًا جديدًا أُضيف؟ (أربع طبقات)

لا توجد صفحة «أُضيف حديثًا» معروفة، وفهارس السنوات ليست مرتبة بتاريخ الإضافة، لذلك يجمع السكربت عدة طرق وكلها تغذّي نفس الطابور (والمعرّف لا يُجلب مرتين):

| الطبقة | الأمر | ماذا تلتقط | التكلفة |
|---|---|---|---|
| 1. صفحات الجديد | `update` | ما يظهر في يعرض حاليًا/قريبًا/دليل القنوات/رمضان/الإيرادات | بضعة طلبات |
| 2. الفهارس الكاملة | `update --mode full` | كل عمل لسنة تاريخه الحالية أو القادمة (~80 صفحة للسنة) | ~160 طلبًا |
| 3. خريطة الموقع | `update --sitemap` | كل عمل مسجّل في sitemap إن وُجدت (الأدق إن وُجدت، وقد تحمل `lastmod`) | ملف أو عدة ملفات |
| 4. تتبع المعرّفات | `update --probe-misses 100` | الأعمال الجديدة تأخذ معرّفات أعلى من الأحدث عندك، فيجرّب `/work/<الأعلى+1>` وما بعده حتى يتوالى 100 إخفاق | عشرات الطلبات |

**ابدأ بهذا الفحص (دقيقة واحدة)** لتعرف أيّها يعمل على الموقع:
```bash
python3 elcinema_scraper.py sitemap --dry-run     # هل توجد خريطة؟ كم عملًا؟ هل فيها lastmod؟
python3 elcinema_scraper.py backfill --years 2026 --limit 100   # املأ القاعدة ببعض الأعمال أولًا
python3 elcinema_scraper.py update --probe-misses 100           # راقب سطر «تتبع المعرّفات: جُرّب X، وُجد Y»
```
- إن وُجدت خريطة فيها الأعمال → استعمل `--sitemap` وحده غالبًا (الأخف والأدق).
- إن لم توجد → اجمع الطبقات 1 + 4 كل ساعة، والطبقة 2 مرة يوميًا.
- في تتبع المعرّفات: إن كان `وُجد` صفرًا رغم وجود أعمال جديدة فالمعرّفات مشتركة مع الأشخاص، فارفع `--probe-misses` (مثلًا 500).
- `--max-new` (افتراضيًا 200) يمنع أول تشغيل لـ `--sitemap` من جلب الكتالوج كله؛ الباقي يبقى في الطابور لتجلبه بـ `fetch-pending`.

**الإعداد الموصى به للجدولة:**
```cron
7 * * * *   cd /path && .venv/bin/python elcinema_scraper.py update --sitemap --probe-misses 100 >> update.log 2>&1
40 3 * * *  cd /path && .venv/bin/python elcinema_scraper.py update --mode full >> update.log 2>&1
15 */4 * * * cd /path && .venv/bin/python elcinema_scraper.py schedules >> schedules.log 2>&1
```
ملخص كل دورة يوضّح مصدر ما اكتُشف: `أعمال جديدة مكتشفة: N (صفحات/فهارس=…، sitemap=…)` ثم سطر تتبع المعرّفات.

## ماذا يُخزَّن (`elcinema_data/elcinema.sqlite`)

| الجدول | المحتوى |
|---|---|
| `works` | العنوان (عربي/بديل)، السنة، النوع (فيلم/مسلسل/…)، التقييم وعدد الأصوات، المدة، الحالة، الملصق، الإعلان، القصة، التصنيف الرقابي، الدول، اللغات، الأنواع، تواريخ العرض لكل دولة، المخرجون، المؤلفون، أبطال الواجهة، مواقع التصوير، الإيرادات، عدد الحلقات، روابط المشاهدة، وأي حقول إضافية في `extra` |
| `credits` | الطاقم الكامل (من `/work/ID/cast`): شخص، قسم، دور |
| `episodes` | حلقات المسلسل (رقم + ملخص) |
| `queue` | طابور الاكتشاف وحالة كل عمل (`pending/done/missing/error`) |

بالإضافة إلى `html_cache/` وفيه نسخة HTML خام مضغوطة لكل صفحة جُلبت، فيمكنك تعديل المحلّلات
وإعادة التحليل دون إعادة الجلب من الموقع.

## الإضافات: مواعيد السينمات، دليل القنوات، الصور، التعليقات

مفعّلة افتراضيًا (`--extras all`) وتُجلب فقط عندما تحمل صفحة العمل رابط القسم المعني، فلا تُهدَر طلبات على أعمال قديمة.
للتحكم: `--extras none` أو `--extras gallery,comments` (أي مجموعة من `showtimes,tvguide,gallery,comments`).

| الجدول | المحتوى |
|---|---|
| `showtimes` | لكل (عمل، يوم، سينما): اسم السينما ومعرّفها، قائمة الأوقات (النص الأصلي + 24 ساعة + علامة «بعد منتصف الليل»)، رابط الحجز |
| `tv_airings` | لكل عرض على قناة: القناة، التاريخ (مُستنتج السنة)، الوقت (أصلي + 24 ساعة)، رابط الاشتراك |
| `gallery` | معرّف الصورة، صفحتها، المصغّرة، رابط الأصل المرجّح، الوصف، المسار المحلي إن نزّلتها |
| `comments` | المراجعات «أراء حرة» (`kind=review`، من `/work/ID/review`): العنوان والكاتب والتاريخ والنص وعدد «مفيد». والتعليقات العامة (`kind=comment`) إن وُجدت في HTML |

**المواعيد والدليل لقطات لحظية** (تُستبدل في كل تحديث ولا تُخزَّن في الكاش). للإبقاء عليها حديثة شغّل:
```bash
python3 elcinema_scraper.py schedules        # كل 3–6 ساعات مثلًا
```
يمرّ على أعمال «يعرض حاليًا/قريبًا/دليل القنوات»، ولا يمسح اللقطة القديمة عند فشل شبكة مؤقت، بل عند 404 صريح فقط.

**الصور:** البيانات الوصفية تُحفظ دائمًا. لتنزيل الملفات نفسها أضف `--download-images` (حتى `--max-images` لكل عمل، افتراضيًا 50) فتُحفظ في `elcinema_data/images/<id>/`.
رابط الأصل `full_url_guess` مستنتج بحذف بادئة المقاس من اسم الملف؛ إن لم يوجد يُستخدم المصغّر تلقائيًا.

**التعليقات:** إن كانت تُحمَّل بـ JavaScript فلن تظهر في HTML. افتح أدوات المطوّر ← Network أثناء تحميل صفحة عمل، وابحث عن طلب يعيد التعليقات، ثم مرّر قالبه:
```bash
python3 elcinema_scraper.py fetch --ids 2099773 --comments-url "https://elcinema.com/<المسار-الذي-وجدته>/{id}"
```

التصدير: `export --format jsonl` يضم كل شيء داخل كل عمل، و`export --format csv --table showtimes` (أو `tv_airings` / `gallery` / `comments` / `credits` / `episodes`) لجدول واحد.

> تنبيه: محلّلات هذه الإضافات مبنية على ما يظهر في صفحة العمل الرئيسية (تبويبات الأيام، قائمة السينمات، جدول القنوات، روابط المعرض)،
> ولم أتمكن من فحص صفحاتها الفرعية الكاملة. شغّل `inspect <id>` على فيلم معروض حاليًا ومسلسل يُعرض على القنوات،
> ويطبع لك عدد كل إضافة ونموذجًا منها. وإن خرجت فارغة فأرسل لي HTML الصفحة الفرعية وأعدّل المحلّل.

## الأداء والتهذيب

- التأخير الافتراضي 1.5 ثانية بين الطلبات (+ عشوائية)، وطلب واحد في كل مرة، ويحترم `robots.txt` و`Crawl-delay` و`Retry-After`.
- كل عمل = طلب للصفحة + طلب للطاقم (+ الحلقات للمسلسلات). للتسريع على القاعدة الكاملة: `--no-cast --no-episodes` أولًا، ثم أكمل الباقي لاحقًا.
- القاعدة كاملة قد تستغرق أيامًا بهذا المعدّل؛ يمكنك رفع السرعة (`--delay`) بالاتفاق مع الموقع، أو طلب تصدير مباشر منهم بحكم الترخيص.
- `--ignore-robots` موجود لكن لا تستخدمه إلا إذا كان ترخيصك يغطي ذلك صراحة.

## تعديل المحلّلات

كل المحلّلات في قسم «التحليل» داخل السكربت: `parse_work` و`parse_people` و`parse_episodes` و`parse_listing`.
الأعمدة العربية (إخراج، تأليف، بلد الإنتاج …) معرّفة في `_FIELD_SRC` — أي عنوان غير معروف يُحفظ تلقائيًا في `extra`.
محلّلات الإضافات: `parse_showtimes` و`parse_tvguide` و`parse_gallery` و`parse_comments`.
غير مغطّى حاليًا: مواعيد سينمات الخليج (`/soon/gulf` تُفحص للاكتشاف فقط)، وصفحات الأشخاص.
